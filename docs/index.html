获客助手

在自己的浏览器里采小红书和抖音的帖子和评论，挑出想找对象的人，把私信和评论发出去。Mac 和 iPhone 都能用，跟手机版 app 是同一套规则，数据可以互相导入。

安装脚本

先装一个脚本管理器

浏览器本身没有采集能力，要靠脚本管理器把这个脚本挂到小红书和抖音的页面上。三种搭配，挑一种就行。

Mac 上用 Chrome

  1. Chrome 应用商店搜 Tampermonkey，点添加至 Chrome。
  2. 回到这一页，点上面的安装脚本，Tampermonkey 会弹出安装页，点安装。

Mac 上用 Safari

  1. App Store 搜 Userscripts，免费，装上。
  2. 打开 Safari 的设置，扩展，把 Userscripts 勾上，权限选允许访问所有网站。
  3. 点一下地址栏左边的 Userscripts 图标，按提示选一个文件夹当脚本目录。
  4. 回到这一页，右键点安装脚本，选下载链接文件，把下载到的 xhs-collect.user.js 拖进刚才那个文件夹。

iPhone 和 iPad

  1. App Store 搜 Userscripts，免费，装上。
  2. 打开系统设置，Safari，扩展，把 Userscripts 打开，权限选允许。
  3. 打开 Userscripts 这个 app，按提示选一个文件夹当脚本目录，在文件 app 里新建一个就行。
  4. 用 Safari 打开这一页，长按上面的安装脚本，选下载链接文件。
  5. 打开文件 app，把下载里的 xhs-collect.user.js 移到第三步那个文件夹。

移不过去就退回来点复制脚本全文，再到 Userscripts 里新建一个脚本粘贴保存，效果一样。

装完之后打开小红书，右下角应该出现一个红色的获客按钮。没出现就是脚本没生效，回到脚本管理器里确认这条脚本是打开状态。

怎么用

  1. 用浏览器打开 xiaohongshu.com，用平时那个号登录。脚本不碰账号密码，登录是你自己在小红书页面上完成的。
  2. 点右下角的获客按钮。
  3. 选行业，勾几个关键词，填要采几篇、多少分钟采完。
  4. 点开始采集，然后让这个页面一直开着。

采集期间页面会自己搜词、翻页、逐篇打开帖子，你能看见它在做什么，随时能暂停或者停止。中途关掉标签页也不会丢进度，下次打开小红书会接着上次那篇继续。

为什么这么慢

默认三十分钟采五十篇，平均半分钟一篇。这个速度是照着手机版定的，不是没优化。

小红书识别批量行为看的是节奏，不是浏览器指纹。短时间内密集访问，轻的是接口开始返回空数据、弹出滑动验证，重的是账号直接被封。代价不对等：慢一点最多是一轮采集多花几小时，反正跑在后台；号一旦没了，登录态和后面所有的采集全部归零。

想快可以把分钟数调小，但每篇之间最少也会隔三秒，那是页面渲染评论要的时间，再快抓回来全是空的。

手机上要注意

  • Safari 切到后台或者锁屏之后会把页面挂起，采集跟着停。要采就让这个页面在前台开着，屏幕别熄。
  • 一个词采三篇要四十分钟以上，八个词全勾要跑六到九小时，这活适合放在手机充电闲着的时候干。
  • iPhone 上导出的文件会存进文件 app，可以直接发给电脑。

数据在哪

全部存在这台设备的浏览器里，不上传任何服务器。这个网站本身是几个静态文件，没有后端，收不到你的数据。

换设备或者要在电脑上看，走面板里的导出全部数据，得到一个 json 文件，在看板里打开就能看，也可以在另一台设备的面板里导入，两边的数据会合到一起。

导出的表格跟手机版 app 的字段完全一致，两边的数据能摞在一张表里。

面板里有什么

采集选词、定参数、看进度和日志
帖子采到的帖子，按点赞排，点开看原帖
人名单加发送，默认只看评论区的人，底下两个按钮是批量私信和批量评论
私信发过谁，他当初说了什么，我们回了什么，成没成
设置行业、发送节奏、评论话术、导出导入清数据

人这一页会先过一道筛选：广告号和同行剔掉，敏感内容剔掉，说过别联系的永久拉黑，剩下的按意向分高中低，无意向的不显示。名单上每个人下面那句话是照他自己写的要求生成的，里面的身高学历是套出来的，发之前要改成真人的条件。

发私信和发评论

在人这一页点私信几个人，脚本会挨个打开这些人的主页，把话填进聊天框发出去，发完核对一遍聊天记录里有没有这条，对得上才算成功，记进私信那一页。核对不到就明写查不到，不含糊报成功，因为一天只有几条额度，报错了既烧了额度又没发出去。

同一个人不会发第二遍，不管上次成没成。发过的人都在私信那一页里。

点评论几篇是去帖子底下留言，话从设置里勾上的那几条里随机挑。回复某个评论者时，脚本会先在评论区找到他那条评论点回复，挂在他下面他才收得到通知。

公开评论的最后一下要你自己按。脚本只把话填进输入框，面板上会出现一个我发过了的按钮，你在页面上按完发送再点它。评论是贴在别人门面上的，最招举报，这一下不能交给程序。

小红书主页上那个私信键在浏览器里点不动，它只认真手指按的那一下，脚本派多少事件它都不理。所以轮到小红书的私信时，脚本会把那个键标红停下来等你按一下，按完它接着把话填进去发出去。抖音的私信键脚本点得动，全程不用管。

发多快

默认一批发二十个，二十分钟发完。这个总时长会被随机切成长短不一的若干段，不是均匀发的。真人本来就不是均匀发的：刷到一批合适的人集中发完，然后放下手机，这才是正常节奏；全天每五分钟准时发一条，反倒一眼就是机器。

两条之间至少隔二十秒。设置里把人数调大或者时间调小到平均三十秒一条以下，保存时会提醒你比真人快，但还是照发，快慢你自己定。

两个平台各存各的

面板右上角写着现在在哪个平台，点一下跳到另一个。这不是开关：浏览器的数据是按网站分的，抖音采的东西存在抖音名下，小红书的存在小红书名下，天然分开。要合起来看就两边各导出一份，都丢进看板。

这套东西跟手机版 app 用的是同一套接口、同一套判断规则、同一套话术，数据可以互相导入。
